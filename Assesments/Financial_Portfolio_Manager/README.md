# 💼 Financial Portfolio Manager

A multi-agent AI app that analyzes your financial profile and generates a **personalized investment report**.

## 🧠 Powered by:
- **Google Gemini 2.5 Flash**
- **Microsoft AutoGen**
- **Streamlit UI**

---

## 🔥 Features

- 🧮 **Portfolio Analyst**: Evaluates your assets and income
- 🚀 **Growth/Value Strategist**: Suggests investments tailored to your risk and strategy
- 📊 **Financial Advisor**: Compiles a professional markdown-formatted report
- 🔒 Gemini API via `.env`, never stored in code
- 🖥️ Streamlit UI with download support

---

## ⚙️ Installation

### 1. Clone the repo
```bash
git clone <your-repo-url>
cd Financial_Portfolio_Manager
2. Install dependencies

pip install -r requirements.txt
3. Add your API key
Create a .env file:


GOOGLE_API_KEY=your_gemini_key_here
Get key from https://aistudio.google.com/app/apikey

🚀 Run the app

streamlit run app.py
